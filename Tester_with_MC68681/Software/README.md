Software for Tester-with-MC68681 configuration.  This is a general purpose 68000 SBC.  It bootstraps from the CF disk that loads and runs a monitor program.  The monitor has functions to display memory, modify memory, execute from specified location, and load S-records.  It also has 3 additional commands to load and run three programs installed in CF disk: TUTOR v1.3, EhBASIC, and CP/M68K.

The image_MC68681 contains bootstrap, monitor, TUTOR, EhBASIC, and CP/M68K.  Use Win32diskimager to copy image_MC68681 to a new CF disk in Windows workstation.
